RCL PLASTIC WEBSITE

Файлы:
- index.html — главная страница
- style.css — весь дизайн
- script.js — русский/английский переключатель и форма

Как опубликовать на GitHub Pages:
1. Откройте ваш репозиторий.
2. Удалите старый index.html или замените его.
3. Загрузите index.html, style.css и script.js в корень репозитория.
4. Settings → Pages → Deploy from a branch → main → /root.
5. Сохраните изменения.
6. Через несколько минут сайт обновится.
